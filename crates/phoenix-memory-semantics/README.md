# Phoenix memory semantics

Domain-general, proposal-only semantic vocabulary and detachable lenses for
`PhoenixGraphGenerationV3`.

This crate does not own source text, canonical entities, decisions, accepted
topology, or publication. It emits evidence-bound candidate drafts. Disabling
a lens removes only that lens's proposals.

`DeterministicAdjudicatorV1` combines bounded GLiClass Instruct memory-event
observations with dedicated ModernBERT-NLI proposition relationships. Its
fixed decision table emits a policy proposal only; every proposal still
requires an explicit immutable decision before truth can change.

The lanes are enforced rather than interchangeable. GLiClass must carry the
steerable semantic-observer role, while NLI must carry the dedicated NLI role.
Corrections close validity only with authoritative source evidence and explicit
correction cues. Different scopes are retained together, later states close
and replace, hypothetical statements remain candidate-only, and unresolved
conflicts open a dispute. No rule uses age-based decay.
