# Changelog

## 0.2.0

- Add an optional `gpui-component` color-picker bridge.
- Add stable-ID palette drafts with empty, solid, and multi-color states.
- Add read-only pointer selection and grapheme-aligned range fills.
- Add positioned and hard stops with sRGB, linear-sRGB, and Oklab interpolation.
- Add built-in, JSON-capable, versioned presets and Rust builder export.

## 0.1.0

- Add bounded, Unicode-aware animated gradient text rendering for GPUI.
